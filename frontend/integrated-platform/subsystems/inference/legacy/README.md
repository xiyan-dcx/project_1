# 前端功能说明

## 概述

基于 FastAPI + SSE 的云边协同视频理解 Web 界面，支持视频多模态问答与纯文本对话，实时展示三阶段推理流水线。

访问地址（内网）：`http://10.166.33.36:8080`

启动方式：
```bash
cd frontend && python server.py
# 可选：PORT=8080 EDGE_URL=... CLOUD_URL=... python server.py
```

---

## 界面布局

单列居中布局，最大宽度 600px，从上到下分三个区域：

```
┌─────────────────────────┐
│        输入卡片          │  ← 始终可见
├─────────────────────────┤
│      推理流水线卡片       │  ← 首次提交后出现，永久保留
├─────────────────────────┤
│      推理结果（列表）     │  ← 逐条追加，不清除
└─────────────────────────┘
```

---

## 功能说明

### 1. 输入区域

| 元素 | 说明 |
|------|------|
| 视频下拉框 | 自定义多选下拉，列出服务器 `data/ssv2_videos/` 下最多 10 个 `.webm` 文件 |
| 问题文本框 | 自由输入提示词，支持多行 |
| 发送按钮 | 提交请求；处理期间禁用防止重复提交 |
| 快捷键 | `Ctrl/Cmd + Enter` 触发发送 |

**多选视频：** 点击下拉框后可逐个勾选，选中的视频以标签（pill）形式展示在下方，点击 × 可单独移除。未选择任何视频时进入纯文本模式。

### 2. 推理流水线（视频模式）

选择视频后提交，流水线卡片出现并实时更新，三个阶段依次执行：

| 阶段 | 说明 |
|------|------|
| **抽帧** | 解码视频，提取均匀帧 + 运动帧，显示总帧数与视频难度分 |
| **任务评估** | 双采样边缘推理，输出路由动作（保留边缘 / 本地补看 / 升级云端）及综合评分 |
| **网络路由** | 按路由策略分发并执行推理，显示最终路径 |

每个阶段完成后显示实际延迟（秒），阶段间连接线动画填充。

**多视频批处理：** 选择多个视频时，逐个顺序处理，流水线卡片复用并显示当前进度（如 `2 / 3`）。

### 3. 纯文本模式

不选择视频直接提交，跳过流水线，直接调用云端模型（P3-02）返回结果。

### 4. 推理结果

每次处理完成后，在流水线卡片下方追加一张结果卡片，包含：

- 文件名（或"文本问答"）
- 来源标签：`Edge`（边缘）/ `Cloud`（云端）/ `Edge fallback`（云端失败降级）
- 模型回答
- 各阶段延迟 chip：抽帧 / 评估 / 路由 / 总计
- 路由路径说明（如 `stay_edge_verified`）

结果卡片**只追加不清除**，刷新页面才会重置。

---

## 路由路径说明

| 路径标识 | 含义 |
|----------|------|
| `stay_edge_verified` | 边缘双采样一致，验收通过，直接返回 |
| `local_resample_then_edge` | 补帧后重判，仍留边缘 |
| `local_resample_then_cloud` | 补帧后不确定，升级云端 |
| `direct_cloud` | 首判即决定走云端 |
| `cloud_failed` | 云端失败，降级使用边缘结果 |

## 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `PORT` | `8080` | 监听端口 |
| `EDGE_URL` | `http://10.166.33.43:8002/v1/chat/completions` | 边缘模型地址 |
| `CLOUD_URL` | `http://localhost:8003/v1/chat/completions` | 云端模型地址 |
| `EDGE_NUM_FRAMES` | `4` | 边缘均匀采样帧数 |
| `EDGE_MOTION_FRAMES` | `4` | 边缘运动采样帧数 |
| `EDGE_RESAMPLE_FRAMES` | `6` | 补帧数 |
| `CLOUD_NUM_FRAMES` | `8` | 云端采样帧数 |
| `EDGE_MAX_SIDE` | `448` | 边缘图像最长边（px） |
| `CLOUD_MAX_SIDE` | `672` | 云端图像最长边（px） |
