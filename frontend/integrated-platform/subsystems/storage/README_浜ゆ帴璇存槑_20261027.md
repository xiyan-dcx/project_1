## 前端开发

本机已使用 Node.js 20.20.2 安装 pnpm 10.34.9，并按 v9 锁文件完成依赖安装。在项目根目录操作：

```bash
cd '/home/p3-02/Storage separation/scalaafa-frontend'
export PATH="$HOME/.local/bin:/usr/bin:/bin:$PATH"
pnpm --dir apps/system-3 install --frozen-lockfile --registry=https://registry.npmmirror.com
bash scripts/start-dev.sh
```

默认入口为 `http://127.0.0.1:5173/system-3/`，只监听服务器回环地址。
需要按用户要求通过校园网直接访问时，执行 `bash scripts/start-dev.sh --host 0.0.0.0`，对应地址 `http://10.166.33.36:5173/system-3/`。启动脚本自动加入 pnpm 路径，已装好依赖时无需重复安装。
在本机通过已有 SSH 登录方式建立本地端口转发后访问。
接口代理默认为 `http://10.166.33.158:30082`，可通过 `SYSTEM3_API_TARGET` 修改。
编译命令：`pnpm --dir apps/system-3 build`，输出到 `apps/system-3/dist/`。
这里保留了项目原有测试文件，本次文件交接没有重新执行构建、测试或压测。

## 总前端系统集成

基础路径：`/system-3/`。Vue Router 配置见 `src/router/index.ts`，服务基础路径见 `vite.config.ts`。
浏览器 API 基础地址默认 `/system-3/api`，WebSocket 默认 `/system-3/ws`，见 `src/config/endpoints.ts`。
部分整套系统页面也直接使用 `/system-3/api/optimization/...`，更改挂载前缀需同时修改这些引用。
反向代理需将 `/system-3/api/...` 转为原后端 `/api/...`，将 `/system-3/ws` 转为原后端 `/ws`，并支持 WebSocket 升级。
非资源路径刷新时应回退到前端 index.html，以支持 Vue Router 深层路径。
整套系统页当前引用固定报告 ID `optimization-bf065af8406a4a6fa7b34b2de5407c5a`，移到独立后端时需一并接入该数据或调整报告选择逻辑。

线上页面：`http://10.166.33.158:30083/system-3/`。
后端部署：`dashboard-caas`；CaaS 服务：`caas-compare-runner`。
这次交接复制源码和静态产物，p3-02 上不会因此自动启动新服务；现有运行系统仍在原位置。
