# 服务器 30082 只读接入

本地 Vue → Vite 同源代理 → 本地 FastAPI 只读适配层 → 服务器 HTTP 健康接口 / WebSocket。

## 入口与启动

远端只读页面：http://127.0.0.1:5174/system-3/

在项目根目录打开两个 PowerShell 终端：

```powershell
.\scripts\start-remote-api.ps1
```

```powershell
.\scripts\start-remote-ui.ps1
```

后端监听本机 8001，前端监听本机 5174；保留原 8000/5173 本地开发服务，不需要停掉它们。两个新终端分别 Ctrl+C 停止。当前轮次已启动这两个服务，再次启动前先确认端口是否空闲。

启动脚本通过 Node import 读取 packages/config/system_config.ts 中的 ENGINE_TARGET；30082 是模块本地端口，没有新增总平台共享变量。Python 通过 SYSTEM3_REMOTE_URL 接收地址，不读取或复制 SSH 密钥。

## 适配行为

- 远端仅 GET `/api/health`、GET `/api/caas/health`，每轮结束 5 秒后再检查。
- 订阅远端 `/ws`，不向它发送应用层命令；WebSocket ping/pong 仅用于检测连接。
- 本地 `/api/state` 使用远端 WebSocket 首帧及后续消息形成的内存快照。不是向远端不存在的 `/api/state` 请求，也不从实验文件补历史数据。
- 本地 `/api/engines` 是三引擎展示契约，不表示服务器允许三个引擎执行；不兼容样本（例如 dPP）不混入比较，显示被忽略的快照样本数。
- 本地拒绝所有非 GET/HEAD HTTP 请求（403），不提供通用转发；`run_enabled` 永远是 false，与环境变量 BENCH_ENABLE_RUN 无关。
- 断开上游时自动重连；界面标记快照已过期，旧数据不当成新实时数据。数据只缓存内存，适配层重启后等待新首帧。
- API 可达、WebSocket 连通、下游健康通过是不同状态；健康检查通过也不等于设备可写。
- 下游故障只读展示，不自动挂载、不恢复服务、不启停 SPDK/FEMU、不触发 fio 或 K8s Job。
