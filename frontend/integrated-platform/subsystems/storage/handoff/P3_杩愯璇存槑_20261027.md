从 master 侧和本机读取页面、health、engines、现有整套系统结果均正常，WebSocket 握手及首帧也正常。
该检查没有提交新的基准任务，也没有修改引擎运行门禁。

管理命令（在已有 Kubernetes 管理权限的 master 会话执行）：

```bash
kubectl -n scalaafa-platform get deployment scalaafa-frontend-p3
kubectl -n scalaafa-platform logs deployment/scalaafa-frontend-p3 --tail=80
kubectl -n scalaafa-platform rollout restart deployment/scalaafa-frontend-p3
kubectl -n scalaafa-platform rollout status deployment/scalaafa-frontend-p3 --timeout=90s
```

Deployment 参考清单位于同目录 `p3-frontend-deployment.json`。
当前为源码开发/交接服务，正式集成总平台时应使用编译后的 dist 及正式静态服务部署。
业务按钮仍受后端设备安全校验、引擎白名单和任务互斥约束。dPP 独立重复入口由原后端禁用，原因见网页。
