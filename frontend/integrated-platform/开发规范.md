## 每个系统

以下为已确认的 Vue 3 + TypeScript 工程结构：配置文件位于子系统根目录，源码位于 src/，不额外增加 frontend/ 层级。

```text
OMS-vue/
├── src/
│   ├── api/                 # 后端接口及相关数据适配
│   ├── assets/              # 图片、图标、样式
│   ├── components/          # 本系统内部复用组件
│   ├── views/               # 页面
│   ├── router/              # Vue Router
│   ├── stores/              # Pinia
│   ├── App.vue
│   └── main.ts
├── index.html
├── package.json
├── vite.config.ts
├── tsconfig.json
└── system_config.ts         # 暂存本系统非敏感统一配置
```

Python 后端和数据保持在子系统根目录的原有相对位置，避免影响流水线。构建输出为根目录 dist/。额外目录按实际需要增加，不预建空抽象层；暂不建设总门户和 packages 公共组件。

## OMS 视觉与交互规范

**极简 · 黑白 · 克制，充分留白，拒绝装饰性特效。**

- 白色或近白背景，深灰正文、中灰说明、浅灰分隔；无彩色品牌强调色、无默认蓝色主色、无大面积黑侧栏。
- 主要按钮黑底白字，次要操作白底细边框或文字按钮。同一区域只突出一个主要动作。
- 状态通过文字、图标、边框及线型表达，不依赖红黄绿或仅靠灰度。危险操作需明确说明作用范围并确认。
- 使用 4/8/12/16/24/32/48px 间距体系；桌面页面边距与区块间距以 24–32px 为主，小屏边距以 16px 为主。减少卡片嵌套，不添加无意义指标卡或欢迎横幅。
- 表单限宽约 720px，报告约 800–960px；表格和拓扑按需利用空间，不以留白为由隐藏必要信息。
- 系统字体，正文 14–16px，页面标题 22–24px；IP 和事件 ID 按需等宽显示。Lucide 图标统一线宽、常用 16–20px。
- Element Plus 采用细边框、小圆角、默认无阴影；只有浮层保留必要轻阴影。
- 禁止渐变、毛玻璃、发光、粒子、背景纹理、流光连线、入场动画、悬浮位移、缩放与弹跳。必要状态过渡不超过约 150ms，支持减少动态效果。
- 拓扑黑白灰静态显示，真实连接与推断传播使用不同线型和图例；不能虚构主机或将推断当作真实网络。
- 普通文字对比度至少 4.5:1，必要控件边界与焦点标识至少 3:1。键盘焦点清楚，图标按钮有可访问名称，错误有文字说明。
- 主题与排版集中在 src/assets/，不散布魔法色值、不大量使用 !important，不为了主题再包装公共组件库。

验收原则：去掉一个装饰元素后，如果不影响理解和操作，就优先去掉。极简不能牺牲功能完整性、可读性或可操作性。

## 注意
总平台部分嘉浩负责
在research-platform/packages/config的里面需要有一个配置文件，例如叫“system_config.ts”
里面需要规定统一的ip和一些共同量，例如“system_config.ts”中
export const ENGINE_TARGET = '10.0.0.1'

后面每个系统自己在对应的地方import，然后使用ENGINE_TARGET代替ip

当前 OMS 独立开发阶段，统一配置临时放在根目录 system_config.ts；接入总平台时再改为 packages/config 导入。浏览器使用同源 API，模型密钥不得进入该配置或 VITE_* 变量。
